# SOC Analyst Home Lab – Day 1

## Project Overview
I am building a practical Security Operations Centre (SOC) home lab to develop hands-on cybersecurity skills and prepare for a career as a SOC Analyst.

This project follows a structured learning roadmap covering virtualisation, networking, SIEM deployment, endpoint monitoring, threat detection, incident investigation and incident response.

## Hardware Specifications

| Component | Specification |
|---|---|
| Processor | Intel Core i7-8700 |
| Physical RAM | 64 GB |
| Storage | 1.75 TB |
| Host Operating System | Windows 11 |
| Hypervisor | VMware Workstation 17 Pro |

## Day 1 Objectives

1. Understand virtualisation and hypervisors.
2. Understand VMware network types: NAT, Bridged and Host-only.
3. Assess hardware and virtualisation capabilities.
4. Plan a segmented SOC network.
5. Establish the project directory structure.
6. Prepare the GitHub documentation workspace.

## Proposed Lab Components

- pfSense Firewall
- Windows Server and Active Directory
- Windows Client
- Ubuntu Server
- Kali Linux
- Wazuh SIEM
- Splunk
- Sysmon
- Security Onion

## Learning Outcomes

By the end of this session, I aim to understand how virtual machines operate, how virtual networks communicate and why network segmentation is important in a security monitoring environment.
